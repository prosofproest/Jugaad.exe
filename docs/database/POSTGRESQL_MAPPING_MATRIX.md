## How verification was done

- Migration chain `0001 → 0004 (head)` verified by
  `alembic upgrade head --sql` (51 CREATE TABLE), fresh-SQLite
  `alembic upgrade head` (51 tables, column parity exact) and
  fresh-PostgreSQL 16.2 `alembic upgrade head` via pgserver (51 tables,
  FK 51, UNIQUE 13, indexes 119, `alembic_version=0004`).
- PostgreSQL timestamp types verified per catalog:
  `users.created_at` timestamp without time zone (UTCDateTime),
  `conversations.created_at` timestamp with time zone.
- PostGIS verification is **skipped/blocked**: pgserver ships no PostGIS
  control file, and the ORM has zero geometry columns by design.
  Production must provide PostGIS (`postgis/postgis:16-3.4`); no spatial
  test is claimed as passed. See SCHEMA_VALIDATION_REPORT.md.
